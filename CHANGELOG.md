# Changelog

## [1.0.0] - 2026-10-09

Prepared initial release; publication pending.

### Added

- Twenty data-first TikTok Ads skills for agency media buyers and paid-social specialists.
- Shared evidence standard, cautious data-export guide, and single-home threshold register.
- Four Python standard-library analysis helpers for creative fatigue, wasted spend, CPA decomposition, and TikTok Shop cost-stack review.
- Copy-paste prompts, synthetic sample data, real script output demos, validation, self-tests, and an install verification script.

### Correctness checks

- Pack-specific shared paths prevent collisions with other installed skill packs.
- Missing, non-finite, or comma-formatted fees stop cost-stack assessment.
- Zero conversions produce an undefined CPA, never an apparent improvement.
- Creative fatigue requires two complete calendar windows; recent spend stays outside conversion-lag decisions.
- CPA mix comparisons use conversion yield; TikTok 6s/2s counts are diagnostic ratios, never viewer retention.

### Guardrails

- No live platform access is required.
- No skill changes ads, budgets, bids, tracking, placements, pages, or Shop promotions.
- Platform-reported results remain separate from profit and independent attribution.
